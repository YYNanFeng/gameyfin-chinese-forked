# Bangumi 插件使用指南

## 📖 关于 Bangumi

**Bangumi 番组计划** (https://bgm.tv) 是一个专注于动画、漫画、音乐和游戏的条目收录站。它提供了丰富的游戏信息数据库，特别是对日本游戏的覆盖非常全面。

## ✨ 插件特性

### 优势
- ✅ **中文友好**: 游戏标题和介绍都有中文
- ✅ **日本游戏覆盖好**: 对日系游戏、Galgame、同人游戏等支持优秀
- ✅ **社区评分**: 提供基于用户评分的排名
- ✅ **免费使用**: 无需注册或 API Key
- ✅ **数据质量高**: 社区维护的高质量数据

### 局限
- ⚠️ 欧美 3A 游戏覆盖较少（建议配合 IGDB 使用）
- ⚠️ 没有游戏截图和视频
- ⚠️ 平台信息可能不够详细

## 🚀 快速开始

### 1. 安装插件

在 Gameyfin 中：
1. 进入 **管理 → 插件**
2. 找到 **Bangumi Metadata** 插件
3. 点击 **安装** 或 **启用**

### 2. 配置（可选）

默认配置即可使用，如需自定义：

```
User Agent: Gameyfin/2.2.1
API Base URL: https://api.bgm.tv
```

### 3. 开始使用

扫描游戏库时，Gameyfin 会自动从 Bangumi 获取游戏信息。

## 🎮 适用场景

### 最佳使用场景

1. **日本游戏库**
   - 日式 RPG
   - 视觉小说/Galgame
   - 同人游戏
   - 主机游戏（任天堂、PlayStation）

2. **中文游戏**
   - 国产独立游戏
   - 中文游戏

3. **补充数据源**
   - 与 IGDB 配合使用
   - 获取中文游戏名称
   - 获取社区评分

## 🔧 配置优化建议

### 多插件组合策略

为了获得最佳效果，建议按以下优先级配置插件：

```
优先级 1: IGDB (欧美游戏、新游戏)
优先级 2: Bangumi (日本游戏、Galgame)
优先级 3: Steam (Steam 平台游戏)
```

在 Gameyfin 插件设置中调整 `ordinal` 值：
- IGDB: 2
- Bangumi: 3
- Steam: 4

数字越小，优先级越高。

### 库分类建议

可以为不同类型的游戏创建不同的库：

```
库 1: 欧美游戏 → 主要使用 IGDB
库 2: 日本游戏 → 主要使用 Bangumi
库 3: Steam 游戏 → 使用 Steam + IGDB
库 4: Galgame → 使用 Bangumi
```

## 📊 数据映射说明

### 评分转换

Bangumi 使用 10 分制，插件会自动转换为百分制：
- Bangumi 8.5 分 → Gameyfin 85%
- Bangumi 7.0 分 → Gameyfin 70%

### 平台识别

插件会尝试从游戏标签中识别平台：
- 标签包含 "PC" → PC 平台
- 标签包含 "PS4" → PlayStation 4
- 标签包含 "Switch" → Nintendo Switch

如果无法识别，默认为 PC 平台。

## 🔍 搜索技巧

### 游戏名称匹配

1. **使用完整名称**
   ```
   ✅ 好: 女神异闻录5 皇家版
   ❌ 差: P5R
   ```

2. **使用官方中文译名**
   ```
   ✅ 好: 塞尔达传说 旷野之息
   ✅ 好: 荒野之息
   ❌ 差: BotW
   ```

3. **日文原名也可以**
   ```
   ✅ 好: ペルソナ5 ザ・ロイヤル
   ```

### 手动匹配

如果自动匹配不准确：

1. 在 Bangumi 网站搜索游戏
2. 找到正确条目的 ID（URL 中的数字）
3. 在 Gameyfin 中手动设置元数据 ID

例如：
```
URL: https://bgm.tv/subject/123456
ID: 123456
```

## 🌐 API 使用规范

### 限流说明

插件自动限制请求速率：
- **每秒最多 1 个请求**
- **最多 2 个并发请求**

这些限制确保不会对 Bangumi 服务器造成过大负担。

### User Agent 规范

请使用有意义的 User Agent，建议格式：
```
AppName/Version (Contact)
```

示例：
```
Gameyfin/2.2.1
MyGameManager/1.0 (email@example.com)
```

## 🆘 故障排查

### 常见问题

**1. 搜索不到游戏**
- 尝试使用中文名称
- 尝试使用日文原名
- 检查游戏是否在 Bangumi 数据库中

**2. 信息不完整**
- Bangumi 可能没有该游戏的完整信息
- 考虑使用 IGDB 作为主要数据源

**3. 平台识别错误**
- 在 Bangumi 网站上为游戏添加正确的平台标签
- 或在 Gameyfin 中手动设置平台

**4. API 请求失败**
- 检查网络连接
- 查看 Gameyfin 日志
- 确认 Bangumi 服务正常

### 查看日志

在 Gameyfin 日志中搜索：
```
[bangumi]
BangumiPlugin
```
